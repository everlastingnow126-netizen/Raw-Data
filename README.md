## Usage

All raw Western blot data presented in the manuscript are provided in the folders below. Each folder is named after the corresponding full membrane from which the images were derived. Images within the same folder were obtained from the same membrane, as evidenced by the cut lines and handwritten markings visible on the corresponding white‑light reference images (labeled “BG”), and further confirmed by the time‑stamp metadata retained in the image properties. Within each folder, the target protein and its corresponding loading control were detected on membrane strips derived from the same transferred membrane and the same set of biological samples. The corresponding membrane strips were processed in parallel, using the appropriate antibody-incubation and exposure conditions for each target. Each folder contains three types of files:

- **White‑light images of the intact membrane (labeled “BG”)** 
- **Raw acquisition files named by exposure time** 
- **Merged images**
